AstroNbodySim.mainloop — Function
mainloop(sim::Simulation) -> Any

Main integration loop: drift → force → kick → analyse → output → repeat until timeinfo.system_time_float >= config.time.End or the user creates a stop file inside config.output.dir.

Returns a Matrix of analyser values if any analysers were registered, otherwise nothing.

Restart / output

saverestart, loadrestart, restart, check_restartable and redistribute_data are part of the restart machinery driven by run / Simulation; they are internal helpers without user-facing docstrings in this release.

Particle-Mesh

The Poisson solvers are provided by PhysicalFFT.jl and PhysicalFDM.jl (no separate docstrings are attached in this package):

  • fft_poisson(Δ, Len, rho, boundary, device) and fft_poisson(mesh, G).
  • fft_poisson!(mesh, rho, boundary).
  • fdm_poisson(mesh, Val(dim), G, mode, device, boundary, sparse).

Machine-Learning solver

The ML solver is experimental; see the ML manual page. No stable training API is exposed in this release.

AstroNbodySim.AdaptiveTimestep — Type
AdaptiveTimestep

Adaptive timestep configuration. The raw step is sqrt(2 * ErrTolTimestep * SofteningLength / |a|), quantised on an integer timeline of length TimeBase and bounded by MinStep and MaxStep.
